## Lessons learned

- **Land a behavior-flip hunk alone and let a test name the ordering
  constraint.** Six plan rounds named the unbounded-ledger-append defect in its
  designed form; none named the intermediate-state form, which a single test run
  surfaced in seconds. Recorded in `workshop/lessons.md`.
- **Judge a stateless gate by finding-provenance, not round count.** Rounds 4-5
  blocked on consequences of rounds 3-4's own fixes — the fix surface moving, not
  the gate re-litigating. Round 6 dropping to Minor was the signal to stop.
- **A behavior change worth restating:** under full migration a live/detached
  legacy session no longer matches what bare `pair` composes, so `pair` creates
  the new `📁` session instead of attaching. The old one stays listed and
  resumable via the picker. Intended — and why the migration wants a quiesced
  state.
- `make test` needs `env -u PAIR_SESSION_ID -u PAIR_TAG -u PAIR_PANE_CWD` inside
  a pair session; `zellij action` needs `dangerouslyDisableSandbox`; `go test`
  caching can mask a sandbox failure — use `-count=1` when checking whether a
  failure is pre-existing.
