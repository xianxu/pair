API behavior:
- tsnet/tsnet.go:556 Start is initOnce.Do; stored failure is sticky, and it begins connection/enrollment side effects. LocalClient:440 calls Start. Neither is a passive accessor. Up:564 waits for Running, then Status and nonempty IP; clears persisted Serve config and advertisements once. NeedsLogin/MachineAuth do not return early (:620); caller context must bound it.
- tsnet/tsnet.go:1409 ListenTLS accepts only tcp, internally calls Up(context.Background()), requires MagicDNS and CertDomains, listens tailnet-only and uses getCert. No cancellation parameter. A timed-out wrapper must retain/join that exact open attempt; never abandon a goroutine/resource or concurrently Close during Start.
- client/local/local.go:345-363 WhoIs is explicitly stable, requires IP or IP:port, returns ErrPeerNotFound on404. ipn/ipnlocal/local.go:1734-1792 resolves address/proxy map against current node/netmap/user profile and returns identity. It neither queries control synchronously nor validates freshness or Expired/KeyExpiry before returning. Positive identity is not authorization freshness proof.
- client/local/local.go:1510-1516 WatchIPNBus is explicitly NOT stable. Next:1663 decodes stream and maps canceled-context errors; Close:1651 idempotently closes body, must be called. Pin adapter and requalify upgrades.
- ipn/backend.go:91-100,297 old initial-netmap bit is rejected; Notify.NetMap removed. Seed NotifyInitialStatus + NotifyPeerChanges (:123-163); add NotifyInitialState and NotifyInitialHealthState. Without peer bit removals/replacements are not delivered. Consume SelfChange (:330), PeersChanged/Removed (:379-396), profiles, plus health; optional patches require handling patch semantics. No generic full-netmap watch assumption.

Teardown and proof limitations / blockers for live implementation:
1. tsnet/tsnet.go:632 explicitly forbids Close before/concurrent Start. Close is once-only (repeat net.ErrClosed), no context and always nil on first completion; it discards child-close errors. :654-704 gives only logtail/local HTTP a5s context, while netstack.Close/lb.Shutdown and waits are synchronous without global deadline. wgengine/netstack/netstack.go:445-453 waits stack/inject goroutines; ipn/ipnlocal/local.go:1321-1408 waits event/control/engine. Therefore no proven5s join bound. Keep revocation immediate; join on owned worker, retain cleanup-unconfirmed after timeout and block reset; do not represent timeout as resource closure. Native cancellation/open/close conformance remains required.
2. WhoIs revalidation alone does not enforce expiry. Inspect returned Node.Expired/KeyExpiry plus self status deadlines and watch health; fail closed on unknown health. local.go:1873-1910 flags expiry on map updates; :2077-2088 supports cached map with no live control client and marks out-of-poll. Status Online uses health.GetInPollNetMap (:1555), which is a local observation, not a fresh remote attestation. No claim of instantaneous revocation or bounded partition detection follows; plan already states propagation limitation. Native revocation/removal and expiry policy must be measured before readiness claim.
3. Narrow watch seam must use exact v1.104.2 Notify schema above; old NetMap consumers will not compile/work. Stable WhoIs does not imply stable watch.
4. State isolation preflight, ambient-refusal, explicit local enrollment, and late-readiness/join tests are required before Start authorization. Static review authorizes no enrollment. ARCH-PURE: keep these policies pure behind adapter; ARCH-FUNERAL: retain one owned close attempt until join and surface uncertainty.
