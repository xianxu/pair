# Project mock server

`couch mock serve DIR [--port N]` runs independently of the Couch supervisor; `couch mock use DIR mock-N` atomically replaces that project's `.mock-current` pointer. Neither command opens a browser or invokes git. The default is the highest numbered mock folder; an explicit missing/broken selection refuses rather than silently changing direction. Optional single-letter style variants (`mock-7a`) sort after the same number's unsuffixed version.

`cmd/internal/mockserve` owns this feature. `project.go` parses/selects versions, pins and verifies directory/file identities through scoped os.Root handles before reading, and owns atomic pointer writes. A project-wide root alone cannot protect private root files from in-root ancestor aliases. `scan.go` visits all project entries and hashes regular content once per scan. File/entry IO is linear; bounded metadata sorting is O(F log F), and content hashing is O(B), for F entries and B bytes. One 500ms loop publishes cached observations for every browser, independent of client count. State requests never walk files. Limits: 1,024 visited entries, 32 MiB total regular contents, 1 MiB per HTML; symlink/special-file and over-limit observations refuse visibly and recover after repair.

`revision.go` owns healthy/error/recovery transitions, with lifetime-qualified revision tokens. `page.go` parses HTML, installs root `data-mock-version` and `data-mock-screen`, and embeds the pre-read baseline before project scripts. Screens use the lowercase `.html` extension. Screen identity is the normalized relative HTML path without `.html`; scenarios in query strings belong to that screen. `reload.js` compares the very first poll against that delivered baseline, navigates on selection change, reloads on content/restart/recovery, and displays errors without discarding the page. Poll requests never overlap and are cancelled on pagehide. Persisted pageshow resumes one loop; generation/request ownership fences late completions from a suspended document.

`server.go` serves GET/HEAD only: selected version HTML/assets, `/fixtures.json`, and the two internal client/state routes. Root design/pointer/other files are private. `/` redirects into the current version URL; a missing HTML screen falls back to that version's index. HTML is parsed with x/net/html; fixture bytes are validated as JSON and served unchanged. Trusted project scripts run normally; this is a local prototype host, not a JavaScript sandbox. No auth, CORS or HTTP writes are introduced. Serve owns the project handle, listener, ticker and scanner; interruption joins owned work before returning. Stalled filesystem IO has no promised wall-clock deadline.

The convention is a `design.md` state list and one fixture response shape shared by every screen; the [sample](../examples/couch-mocks/design.md) includes three linked screens and normal/empty/error/long-list scenarios. Feedback rounds are commits within the current version; new numbered folders are directions worth comparing. Those git choices are operator workflow, not server-enforced policy. Cast-sketch consumes the root identity marks separately (#756); real/mock development routing and production refusal belong to #757.

Verification: package tests cover selection, bounds, confinement, revision transitions, cached reads and shutdown. Opt-in `WEBCAST_LIVE_CHROME=1 go test ./cmd/internal/mockserve -run 'TestMockBrowserReload|TestSampleBrowser' -count=1` drives a private headless browser through clicks, edits, switches/revert and first-observation races. `node --test cmd/internal/mockserve/reload_test.js` covers client request ordering and cancellation. The normal suite exercises deterministic model, filesystem and HTTP behavior.
